# Google Location для MajorDoMo

Модуль для системи розумного будинку **MajorDoMo**, призначений для отримання геолокації та рівня заряду акумулятора членів родини через сервіси **Google Family Link** та **Google Maps Location Sharing (Геопередача)** з автоматичною передачею в модуль **GPS Tracker ([app_gpstrack](https://github.com/sergejey/majordomo-app_gpstrack))** та оновленням об'єктів системи.

Розробник: **[mambursoft](https://github.com/mambursoft)**  
Форк та модернізація на базі модуля `majordomo-google_location`.

---

## 🚀 Основні можливості

1. **Підтримка Google Family Link:**
   - Отримання точних GPS-координат смартфона дитини в режимі реального часу.
   - Отримання рівня заряду батареї (`battlevel`, від 0 до 100%).
   - Отримання стану заряджання (`charging`, 1 або 0).
2. **Постійний шеринг від дорослих членів сім'ї:**
   - Підтримка звичайного Google Maps Location Sharing («Поділитися геоданими» на постійній основі).
3. **Пряма інтеграція з `app_gpstrack`:**
   - Автоматичний фоновий виклик `/gps.php` з параметрами `latitude`, `longitude`, `accuracy`, `speed`, `battlevel`, `charging`, `deviceid`, `provider=google_location`.
   - Повна сумісність з побудовою треків, історією переміщень та входом/виходом з геозон (Дім, Робота, Школа тощо).
4. **Пряме оновлення об'єктів MajorDoMo:**
   - Можливість прив'язати кожного користувача до об'єкта системи (наприклад, `Users.Son`, `Users.Daughter`, `Users.Admin`).
   - Автоматичний запис властивостей: `.Coordinates`, `.Latitude`, `.Longitude`, `.Accuracy`, `.Speed`, `.BatteryLevel`, `.Charging`, `.Address`, `.UpdatedTime`.
   - Виклик методу `.onLocationUpdated` при кожному оновленні координати.
5. **Сучасний картографічний інтерфейс (OpenStreetMap / Leaflet):**
   - Відмова від застарілих та заблокованих сервісів (Яндекс.Карти замінено на Leaflet + OpenStreetMap).
   - Інтерактивна карта в панелі керування та віджет для сцен/дашбордів.
   - Пряме посилання на відкриття точки в офіційному Google Maps.
6. **Опційне використання Google Maps Platform API:**
   - Можливість підключення офіційного Google Maps Geocoding API Key для зворотного геокодування (отримання точної адреси по координатах).
7. **Стабільна сесія:**
   - Емуляція сучасних браузерних заголовків Chrome, автоматична робота з cURL CookieJar, підтримка оновлених токенів Google.

## 🛠 Архітектура та схема підключення

Оскільки компанія Google не надає відкритого Cloud API для отримання приватних GPS-координат користувачів та дітей, модуль використовує рекомендовану в індустрії (Home Assistant, OpenHAB) схему **виділеного акаунта розумного будинку**:

```
[ Смартфон сина ]  --> (Family Link) ──────────────┐
                                                   │
[ Смартфон доньки] --> (Google Location Sharing) ──┼──> [ Виділений Google акаунт ] 
                                                   │    [      розумного будинку   ]
[ Ваш смартфон ]   --> (Google Location Sharing) ──┘                    │
                                                                        │ (RPC locationsharing)
                                                                        ▼
                                                         [ MajorDoMo: google_location ]
                                                                        │
                                                   ┌────────────────────┴────────────────────┐
                                                   ▼                                         ▼
                                     [ Модуль app_gpstrack ]                     [ Об'єкти Users.* ]
                                     (Геозони, треки, історія)                 (.BatteryLevel, .Coordinates)
```

## 📋 Покрокове налаштування

### Крок 1. Налаштування спільного доступу в Google
1. Створіть окремий Google-акаунт для розумного будинку (наприклад, `my.smarthome@gmail.com`).
2. Налаштуйте передачу геоданих на цей акаунт:
   - **Для смартфона сина:** у додатку Google Family Link на телефоні батьків переконайтеся, що відстеження місцезнаходження дитини увімкнено. У Google Maps поділіться геоданими дитини з акаунтом розумного будинку.
   - **Для доньки:** у застосунку Google Maps оберіть *«Передача геоданих» (Location Sharing)* -> *«Поділитися»* -> оберіть акаунт розумного будинку -> встановіть *«Поки ви не вимкнете»*.
   - **Для вашого смартфона:** поділіться геоданими зі свого основного акаунта на акаунт розумного будинку на постійній основі.
3. Увійдіть через браузер на комп'ютері в акаунт розумного будинку на сайті [Google Maps](https://www.google.com/maps). Переконайтеся, що всі 3 маркери відображаються на карті.

### Крок 2. Експорт файлу cookies
1. Встановіть у браузер розширення для експорту кукі (наприклад, **Get cookies.txt LOCALLY** для Chrome/Firefox).
2. Перебуваючи на вкладці Google Maps, експортуйте cookies для домену `.google.com`.
3. Збережіть файл під назвою `cookies.txt`.

### Крок 3. Налаштування модуля в MajorDoMo
1. Перейдіть у панелі MajorDoMo: **Панель керування -> Додатки -> Google Location**.
2. Відкрийте блок **Налаштування**, натисніть **Обрати файл**, виберіть ваш `cookies.txt` і натисніть кнопку додати.
3. Встановіть інтервал оновлення (за замовчуванням 1 хвилина).
4. За бажанням введіть **Google Maps API Key** для зворотного геокодування.
5. Натисніть **Оновити зараз** — у таблиці з'являться ваші пристрої.
6. Для кожного користувача натисніть кнопку редагування (олівець) і за бажанням вкажіть прив'язаний об'єкт (наприклад, `Users.Son`).

## 📦 Встановлення модуля

### Варіант А. Через Маркет доповнень MajorDoMo
1. Завантажте готовий архів `dist/google_location.tar.gz` з цього репозиторію.
2. У панелі MajorDoMo відкрийте: **Панель керування -> Система -> Маркет доповнень -> Завантажити додаток**.
3. Завантажте архів. Модуль автоматично встановиться та створить необхідні таблиці в базі даних.

### Варіант Б. Вручну через Git / копіювання
Склонуйте репозиторій безпосередньо в корінь вашої установки MajorDoMo:
```bash
cd /var/www/html # або C:\_majordomo\htdocs
git clone https://github.com/mambursoft/majordomo-google_location.git /tmp/gloc
cp -r /tmp/gloc/modules/* ./modules/
cp -r /tmp/gloc/templates/* ./templates/
cp -r /tmp/gloc/languages/* ./languages/
cp -r /tmp/gloc/img/* ./img/
```

Після цього відкрийте будь-яку сторінку панелі керування MajorDoMo — модуль автоматично ініціалізується.
